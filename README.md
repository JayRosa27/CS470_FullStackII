# CS 470 – Full Stack Development II

In this course, I worked on moving a full stack question-and-answer application to an AWS serverless environment. I used S3 to host the frontend, API Gateway to route requests, Lambda functions to handle operations, and DynamoDB to store data.

Through this project, I learned more about cloud deployment, Docker containers, API connections, and troubleshooting. I also explored how scaling and cost affect decisions as an application grows.

## Final Reflection

My final reflection covers what I learned, my strengths as a developer, and how I would plan for the application’s future growth.
